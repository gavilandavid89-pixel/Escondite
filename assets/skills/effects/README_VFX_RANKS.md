# VFX de habilidades por rango

PNG independientes por habilidad y rango (1-10). El personaje no forma parte del asset.

Integrados en combate: Kamehameha, Galick Gun, Masenko, Death Beam, Majin Beam, Explosión Namekiana y ráfagas de KI raciales.

Taiyōken y Barrera se mantienen procedurales para conservar el diseño acordado: destello blanco de ~0,5 s y contorno/campo de energía alrededor del personaje.

Regla de impacto: en técnicas con animación temporal, el daño se aplica después del momento de impacto del VFX.
